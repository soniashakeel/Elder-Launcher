# ELDER LAUNCHER BETA 0.1.0 — APK Build Instructions

This directory is the complete Android Studio project for:

- **Application ID:** `com.elder.launcher`
- **App name:** `ELDER LAUNCHER BETA`
- **Version:** `0.1.0`
- **Minimum Android version:** Android 7.0 / API 24
- **Target Android version:** API 34
- **Required NDK:** `25.2.9519653`
- **Required JDK:** 17

## 1. Install Android Studio prerequisites

In Android Studio, open **SDK Manager** and install:

1. Android SDK Platform 34
2. Android SDK Build-Tools 34.0.0
3. Android SDK Command-line Tools
4. NDK (Side by side) `25.2.9519653`
5. CMake, if Android Studio requests it for the native bridge

Make sure Android Studio is configured to use JDK 17:

`Settings/Preferences → Build, Execution, Deployment → Build Tools → Gradle → Gradle JDK`

## 2. Import the project

1. Extract the ZIP archive.
2. In Android Studio, choose **Open**.
3. Select the extracted `android/` directory — do not select the workspace parent directory.
4. Allow Gradle sync to finish.
5. If Android Studio asks for an SDK location, select the SDK installation that contains Platform 34 and NDK `25.2.9519653`.

The project uses these Android Studio modules:

- `MainApp` — the ELDER launcher and Pojav launch pipeline
- `Core` — Android core module boundary
- `JRE` — bundled Java runtime packaging
- `OpenGL` — native/OpenGL module boundary

## 3. Build the optimized beta APK

From the `android/` directory, run:

```bash
./gradlew :MainApp:assembleRelease
```

On Windows:

```bat
gradlew.bat :MainApp:assembleRelease
```

The release build has:

- R8 code shrinking enabled
- Resource shrinking enabled
- ProGuard/R8 rules in `app_pojavlauncher/proguard-rules.pro`
- ABI splits for `arm64-v8a`, `armeabi-v7a`, `x86_64`, and `x86`
- No universal APK, to avoid bundling every native architecture
- The bundled beta debug keystore for immediate local installation

APK files are generated under:

```text
android/app_pojavlauncher/build/outputs/apk/release/
```

There will normally be one APK per ABI. For most physical Android phones, use
the `arm64-v8a` APK.

## 4. Install on a connected device

Enable USB debugging on the Android device, connect it, then run:

```bash
adb install -r app_pojavlauncher/build/outputs/apk/release/app_pojavlauncher-arm64-v8a-release.apk
```

The exact filename may include the version and ABI filter generated by your
Android Gradle Plugin version. List the output directory if needed:

```bash
ls app_pojavlauncher/build/outputs/apk/release/
```

## 5. Build a debug APK instead

Debug builds use the same included keystore and keep debugging enabled:

```bash
./gradlew :MainApp:assembleDebug
```

Debug APKs are generated under:

```text
android/app_pojavlauncher/build/outputs/apk/debug/
```

The debug application ID is `com.elder.launcher.debug`, so it can be installed
alongside the release beta.

## 6. First launch checklist

After installing the release APK:

1. Open **Tools → Performance**.
2. Enable **Low-End Mode** on a 3 GB device.
3. Confirm the memory allocation shows 768 MB.
4. Use **FPS Boost Preset** for Minecraft 1.16.5.
5. Sign in from **Account** using Microsoft Login or Offline Login.
6. Allow the storage permissions requested by Pojav.
7. Install the recommended Java runtime when prompted.

## 7. Important signing note

The release variant is signed with the included Android debug keystore so the
beta can be built and installed immediately. This key is not suitable for
Google Play or long-term public releases. Before publishing, replace
`signingConfigs.customDebug` in `app_pojavlauncher/build.gradle` with a private
release signing configuration and keep that private key outside the project
archive.

The export ZIP intentionally does not include the separate `upload.jks`
credential file. It is not needed for the beta release build and should never
be distributed with source exports.

## 8. Troubleshooting

### SDK location not found

Open the project in Android Studio and set the SDK path in SDK Manager, or set
`ANDROID_HOME`/`ANDROID_SDK_ROOT` in the shell. Do not commit a machine-specific
`local.properties` file.

### NDK version not found

Install NDK `25.2.9519653` from SDK Manager. The required version is declared in
`app_pojavlauncher/build.gradle`.

### Gradle sync fails after extracting the ZIP

Confirm that you opened the extracted `android/` folder and that Gradle is
using JDK 17. Then choose **File → Sync Project with Gradle Files**.

### R8 reports missing classes

Run the release build again after Gradle has downloaded all dependencies. If a
third-party dependency reports a genuinely required missing class, add only
the narrow keep/dontwarn rule needed to `proguard-rules.pro`; do not disable
R8 for the release variant.
